# [Project Name] — Decisions

Track key decisions made during the project. Useful for onboarding and future reference on "why did we do it this way?"

When a newer decision supersedes an older one, strike through only the title using `~~title~~`, update the body to reflect the current state, and add a note: "**Superseded by:** [date + title of newer decision]"

See `projects/_example/decisions.md` for a worked example of this pattern.

## Decision Log

### [YYYY-MM-DD] Decision Title

- **Decision**: What was decided?
