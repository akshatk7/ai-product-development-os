# Reference Documents

This folder holds static reference materials that informed the product but are not actively maintained.

**What belongs here:**
- PDFs (sales playbooks, research reports, strategy decks)
- Foundational analyses that spawned multiple projects
- Competitor research
- External reference materials

**What does NOT belong here:**
- Living documents (those go in Google Docs, linked from project CONTEXT.md)
- Project-specific artifacts (those go in the project folder)
- Data science analyses (those go in `data-science/` if the DS add-on is enabled)

When a reference doc spawns a project, create the project folder under `projects/` and link back to the reference doc in the project's CONTEXT.md.
