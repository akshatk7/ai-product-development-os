Prepare a briefing and agenda for an upcoming meeting by gathering context from all relevant sources.

The user will provide the meeting name or topic and optionally a Google Doc URL.

Instructions:
1. Identify which project(s) the meeting relates to. Read the relevant project CONTEXT.md, decisions.md, and recent updates.
2. Check meeting notes tool (Granola, Otter, etc.) for recent related meetings. Pull transcripts for directly relevant ones.
3. Check for any recent Slack activity in relevant channels.
4. Identify:
   - Open questions from previous meetings that need follow-up
   - Action items that were assigned and their status
   - New context that has emerged since the last discussion
   - Key decisions that need to be made
5. Draft a meeting agenda with:
   - Context section (2-3 sentences)
   - Discussion topics (numbered, with sub-bullets)
   - Key alignment point to close on
6. If the user provided a Google Doc URL, write the agenda there. Otherwise, save as .md for markdown paste.
7. Ask the user if they want to adjust anything.
