# Data Science Conventions

- Organize analyses by time period (e.g., `2026-H1/`) then project name.
- Every new analysis must be added to `data-science/INDEX.md` with: path, projects informed, and key findings.
- When analysis findings inform a product decision, cross-post the key finding to the relevant project's `truths.md`.
- DS scripts should use a `ds_` prefix for clarity.
- Keep charts and CSVs local — only push documentation, key scripts, and findings that the team needs.
