# Digest Meeting — Gotchas

_Updated as issues are encountered. Read before every run._

1. **Don't dump everything into CONTEXT.md.** Decisions go in `decisions.md`, chronological updates go in `updates.md`. CONTEXT.md is only updated when the project narrative changes.
2. **Convert relative dates to absolute.** "Next Thursday" in the transcript → "2026-04-09" in the notes.
3. **Check the meeting → file mapping table.** It's in the root CLAUDE.md. Don't guess where content goes.
4. **Always check strategy/beliefs.md.** Meeting discussions often confirm or challenge existing beliefs. Don't skip this step.
